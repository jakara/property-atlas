(一 ) 天津户籍--人户统一(户口本和房本地址一致 )

2023年入学的适龄儿童必须年满6周岁 ( 2017年8月31日以前出生 ) 。适龄儿童的户籍和合法固定居所均在本区 ，且地址完全
一致。适龄儿童户籍的户主、合法固定居所的产权所有人 ，必须是适龄儿童的父母、祖父母或外祖父母。凡符合以上入学条件的，
按照入学报名时间到户籍所属学区片小学登记报名 。

特别情况说明-- (六年一学位 )

1 .小学一年级登记入学，须持有与和平区户籍地址相同的房产满三年，并设政策过渡期。2023年: 2024年入学，须在2022年
8月31日之前持有; 2025年及以后入学，须持有满三年时间，截至入学当年的8月31日。2021年8月31日之前已持有房产的不受影
响，新房不受持有时间影响 。

2.持有房产不满三年，确因特殊实际困难，适龄儿童无法在天津市其他区落户入学的，须提供相关证明 ，教委根据小学入学位
情况，安排相对就近小学，且小升初时统筹安排到有空余学位的公办初中。

3 .和平区适龄儿童入学还需满足“六年一学位”相关要求，“六年”是指2015年起以一个房屋地址入学的在校生，从该生入
学登记之日到其小学毕业之日，热门学校及学位短缺学校学区内每户地址六年内只享有一次同校对口入学机会。如同一个房屋地址
六年内有多个适龄儿童申请入学，房主和户主必须是适龄儿童相同的父母 ( 或祖父母、外祖父母 ) 。
